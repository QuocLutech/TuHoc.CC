Vue là một framework dung để xây dựng giao diện người dung (user interface) .
-giúp chia một trang web lớn thành nhiều mảnh nhỏ có giao diện và logic riêng gọi là component(thành phần ) , những mảnh này có thể tái sử dụng (reuse). 
-một component vue thường có 3 phần : 
	+ <script setup> //JavaScript - xử lý logic </script>
	+ <template>   <! -- HTML- giao diện -->  </template>
	+ <style> /*Css - Giao diện */ </style>
